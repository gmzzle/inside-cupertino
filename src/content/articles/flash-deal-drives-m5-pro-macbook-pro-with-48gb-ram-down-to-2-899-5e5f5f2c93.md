[AppleInsider](https://appleinsider.com/articles/26/09/09/flash-deal-drives-m5-pro-macbook-pro-with-48gb-ram-down-to-2899?utm_source=rss) spotted a flash sale at B&H that drops the 14-inch MacBook Pro with M5 Pro and 48GB of RAM to $2,899. That's $200 off, which matters when you're already this far into the price curve.

The base M5 Pro starts at 18GB unified memory, so stepping up to 48GB normally costs $400. With this deal, you're effectively getting that RAM bump for $200. Not nothing. The config in question has the 15-core CPU and 16-core GPU, which is the middle Pro chip—stronger than base M5 but not the full 17-core variant. Space Black only, which tracks for B&H's inventory deals.

Here's the thing: 48GB is overkill for most people, but if you're actually using this machine for 4K video timelines, large Xcode projects, or running VMs, you'll use it. The M5 Pro's memory bandwidth makes RAM feel faster than it did in the Intel days, but there's no substitute for just having more of it when you need it. Apple charges obscene margins on RAM upgrades, so any discount here helps.

The timing is cute—B&H is clearly trying to move inventory ahead of whatever Apple announces today. If new MacBook Pros show up in the next month, this deal gets less appealing fast. But if you need a Pro-level machine now and you know you need the memory, $2,899 for 48GB is the best you're going to see on current hardware.

Just don't talk yourself into 48GB because it's on sale. If 18GB would've been fine, save the two grand and get the base model.
